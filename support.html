Frequently asked questions

Start with the common questions.

If the answer you need is not here, send the relevant context by email or open a reproducible issue on GitHub.

Which file types can FT-ITC Analysis open?

FT-ITC Analysis can open MicroCal raw .itc files, TA Instruments / NanoAnalyze .TA exports, PEAQ-ITC .apj projects, compatible integrated .dat, .aff and .dh data, and FT-ITC project files. See the main file-format overview for more context.

Where should I report a reproducible bug?

Use the GitHub issue tracker for reproducible bugs and feature requests. Include the input file type, the expected and observed outcome, and a minimal example when possible.

What should I include in a support request?

Include your operating system, FT-ITC version, input file type, expected and observed result, and the complete error message or terminal output. A screenshot or minimal example can make a diagnosis much faster.

Can support help interpret my ITC data?

Support can help with the software workflow, file handling and technical questions. Scientific interpretation still depends on the experiment, controls, model assumptions and research context.
