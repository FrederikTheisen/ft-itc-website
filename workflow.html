ITC file formats

Supported instruments and file formats for your analysis workflow.

Import compatible raw data, instrument exports, integrated heats and project files from the tools you already use.

.itc

MicroCal .itc raw data

Open raw ITC experiments for inspection, baseline fitting and integration.

.TA

TA Instruments / NanoAnalyze exports (.TA)

Import TA Instruments / NanoAnalyze data exports for processing and analysis.

.apj

MicroCal PEAQ-ITC project files (.apj)

Extract available integrated experiment data from PEAQ-ITC project files for further analysis.

.dat · .aff · .dh

Integrated heats (.dat, .aff, .dh)

Bring in compatible integrated heat data for fitting and further analysis.

.ftxtc · .ftitc

FT-ITC projects (.ftxtc; legacy .ftitc import)

Save current projects as .ftxtc and open legacy .ftitc projects when you need to revisit earlier work.

A first analysis

A dependable route from measurement to result.

01

Open and review

Import one or more files, then check experimental setup and concentrations before processing.

02

Process carefully

Review the thermogram, set the baseline and make peak integration choices that match the experiment.

03

Fit with context

Choose a standard model and read the fit together with the data and residuals—not as an isolated number.

04

Export and record

Save clear figures or processed results and retain the project context behind the result.

Advanced processing

Keep detailed processing decisions under your control.

Refine spline baselines, adjust integration windows and exclude regions that should not contribute to the fitted heats. The processing view keeps those choices visible alongside the thermogram.

Results that communicate

Export figures with the evidence still in view.

Good ITC reporting preserves the relationship between the raw signal, integrated heats, fitted model and residuals. FT-ITC Analysis is designed around this visible chain.
