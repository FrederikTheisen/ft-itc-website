A visible workflow

Work through the experiment without losing the thread.

FT-ITC Analysis keeps experimental data, processing choices and results together instead of treating them as disconnected steps.

01

Open & inspect

Import data and review the experimental setup. Add comments and inspect injections.

02

Process & fit

Adjust baselines, integrate peaks and fit standard models with the underlying data in view. Flexible processing and advanced correction options help recover useful conclusions.

03

Compare & export

Use multi-experiment analyses and make clear figures for your next publication.

Global fitting

Find one model across the experiments that belong together.

Fit multiple isotherms simultaneously while deciding which parameters should be shared and which remain experiment-specific. This is especially useful for systematic changes across conditions, including temperature-dependent relationships such as ΔCp.
