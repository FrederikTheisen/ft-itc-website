Installation steps

Install the application in four steps.

01

Download the installer

Use the download button above to save the Windows x64 setup executable.

02

Open the downloaded file

Open ft-itc-analyis_1.4.2_win-x64-setup.exe from your browser or Downloads folder.

03

Complete setup

Follow the installer prompts to add FT-ITC Analysis to your computer.

04

Launch FT-ITC Analysis

Open FT-ITC Analysis from the Windows Start menu and begin a new project or reopen an existing one.

Updating

Run the newest installer when an update is available.

Download the newer Windows setup executable and run it to update the application. Original data and saved .ftxtc projects are stored separately and are not removed.

Uninstalling

Open Windows Settings, choose Apps, find FT-ITC Analysis in the installed apps list and select Uninstall. Removing the application does not delete original experimental data or saved project files.

Installation support

Need help installing FT-ITC?

If setup or launch does not work as expected, contact support with your Windows version and a description of what happened.
