Core workflow

Make each analytical step inspectable.

01

Import experimental data

Open supported instrument files and review experiment details, concentrations and raw thermograms.

02

Baseline and integration

Fit baselines, adjust peak integration ranges and inspect how choices affect each injection heat.

03

Fit and compare

Fit standard interaction models, explore global or temperature-dependent parameters, and review residuals.

04

Export the result

Export figures and processed results with the visual context needed to communicate the analysis.

Tools for deeper work

Go beyond a single fit when the question asks for it.

Multi-experiment analysis, buffer subtraction, experiment merging and result export help carry related experiments into a coherent analysis.

Local-first by design

Your experimental data remains on your computer.

FT-ITC Analysis does not require an account or upload your experimental data to an FT-ITC service. The desktop application runs locally, while the public repository makes the code and release record available for inspection.
